# FluentFuture

An online platform designed to help ESL learners build confidence, track progress, and improve their English through structured, interactive learning.

---

## Overview

**FluentFuture** is a learner-focused platform that combines assessment, personalization, and engaging content into one streamlined experience. It’s built to support students at different levels while giving them clear direction and measurable progress.

---

## Features

### Language Level Test

- Quick and structured placement test
- Identifies learner proficiency
- Provides immediate feedback and level classification

### Personal Learner Profile

- Individual dashboard for each user
- Tracks completed tests and learning milestones
- Stores progress data for continuous development

### Interactive Lessons

- Engaging, level-appropriate content
- Focus on practical language use
- Designed for active participation, not passive reading

---

## Goals

- Make English learning structured and accessible
- Help learners clearly understand their level and progress
- Provide a personalized learning journey
- Encourage consistent practice through interactive content

---

## Tech Stack

- Frontend: HTML
- Backend: JS
- Styling: CSS
- Auth: Firebase
